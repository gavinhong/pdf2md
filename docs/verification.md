## 打包中发现并修正的问题

RapidDoc 的表格方向辅助模块仍使用包内固定的 `resources/rapid_orientation.onnx`。仅将模型存放在外部目录不足以满足这一内部调用。PyInstaller spec 因此从已校验的本地模型复制同一份方向模型到兼容资源路径，额外约 6.5 MiB，不增加模型种类，也不触发联网。

pywebview 会枚举 JS API 对象的公开属性。将内部服务和原生窗口改为私有属性后，避免递归枚举 WinForms/COM 对象。冻结的无控制台进程为主进程和工作进程分别建立本地日志，避免第三方库使用空 stdout/stderr。

## 实际分发方式

Windows 使用 PyInstaller onedir；完整目录约 1.7 GiB，ZIP 约 1 GiB，包含模型、Python/原生库、前端公式字体和微软固定 WebView2。精确大小与文件清单在发行目录 `package-manifest.json`，归档旁保存 SHA-256。模型目录本身约 772 MiB，其中公式模型约 566 MiB。

未包含 Torch、CUDA、OpenVINO、Electron；没有把开发用 Node.js、测试文件或样本 PDF 放入应用目录。依赖中的 Office 相关代码由 RapidDoc 引用，当前未做破坏上游导入结构的强行裁剪。
